Questions

Open an issue on GitHub

Can I try Dejaview without installing it?

Not yet. Dejaview runs on your own computer; there is no hosted version. The code is public on GitHub.

Which films can it find?

12,543 American films from Wikipedia's yearly lists, 1970 to 2025, plus a few older ones those lists link to. Films from other countries are not indexed yet.

How long does Dejaview take to set up?

About nine hours of computer time on a laptop, mostly unattended: five to crawl, an hour and a half to parse, three to embed the plots.

Does Dejaview send my searches anywhere?

No. The index, the ranking and the model all run locally. The model downloads once, about 90 MB.

Why does a film title sometimes win?

Titles count three times in the index, so "weatherman" can rank The Weather Man above Groundhog Day. Lowering that weight is the next change.
